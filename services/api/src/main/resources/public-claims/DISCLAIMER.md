# Public-claims teasers — not customers, not legal findings

These packs reconstruct **what a fail-closed evidence check can see from public pages**.

They are **not**:

- a customer relationship, a paid engagement, or an implication that the named organisation uses this product
- a legal classification, a notified-body assessment, or an accusation of non-compliance
- an evaluation of the organisation’s private models, training data, or internal approvals
- a substitute for counsel

Risk class on each teaser is an **assisted note** for a readiness conversation. Annex III high-risk duties for those systems apply **2 December 2027** (Regulation (EU) 2026/1744). Article 50 transparency duties have applied since **2 August 2026**.

Evgraph is a **separate Python library** (`pip install evgraph`). This repository exports the JSON/CSV that library already reads. It does not reimplement Evgraph in Java.
